Duplicate Fighter Summons · Mythic Universal Blueprint

A duplicate of a fighter you already own = a blueprint for that fighter (each fighter has a cap). A duplicate summon of a fighter that has reached its cap (fully upgraded) = an upgrade kit + the reward below (fighters chosen from selection boxes or with Mythic Universal Blueprint are excluded). Fully upgraded Legendary: if you still have a Legendary that is not fully upgraded, 2 Legendary blueprint selection boxes; if all Legendaries are fully upgraded, only the kit. Fully upgraded Mythic: if you still have a Mythic that is not fully upgraded, Mythic Universal Blueprint x5. Mythic Universal Blueprint x10 = choose 1 Mythic that is not fully upgraded (the fighter itself if you do not own it, or 1 blueprint if you do). On Mythic nodes, 2 universal blueprints count as 1 blueprint.

Core Part Options

Each Core Part slot has 3 option lines. One [Reroll] = 1 Core Chip (+1 per locked line) and re-rolls every unlocked line (the first roll is free). Each line gets its type and grade separately, and the value is uniform within that grade's band. The 3 lines of a slot are always different types. There is no pity or compensation system.

Grade = one of 5 equal bands of that type's value range (min to max). Grade rates are the same for every slot and every type.
