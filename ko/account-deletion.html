출격! 에이스 계정ㆍ데이터 삭제 요청

개발자: 스튜디오 쿼카 ㆍ 앱: 「출격! 에이스」 (com.studioquokka.ace)

이 페이지는 게임 계정과 관련 데이터의 삭제를 요청하는 방법을 안내합니다. 게임을 이미 지웠어도 요청할 수 있습니다.

1. 게임 안에서 삭제

  1. 게임에서 [기타] 를 누릅니다.
  2. [설정] → [데이터 삭제] 를 누릅니다.
  3. 안내를 읽고 [계속] → [길게 눌러 삭제] 를 2초 동안 누릅니다.

2. 웹 (이메일) 으로 요청

게임을 지웠거나 게임을 열 수 없으면 이메일로 요청해 주세요.

  • 받는 사람: studioquokka.support@gmail.com
  • 제목: 계정 삭제 요청 - 출격! 에이스
  • 본문: 게임 번호 (게임 안 [기타] 화면 아래, 또는 고객 문의 메일 제목에 있는 번호). 번호를 모르면 기기 모델과 마지막으로 접속한 날짜를 적어 주세요.

본인 확인 뒤 30일 안에 처리하고 결과를 이메일로 알려 드립니다.

3. 지우는 데이터

  • 게임 계정 (플레이어 번호) 과 게임 서버의 진행 기록, 순위표 기록, 우편함
  • 플레이 분석 데이터 (동의한 경우)

4. 법에 따라 남기는 데이터

  • 결제 기록: 거래일부터 5년
  • 부정 이용 기록: 기록한 날부터 1년
  • 문의 기록: 처리가 끝난 날부터 3년 (전자상거래법 소비자 불만ㆍ분쟁 처리 기록)

남기는 데이터는 위 목적에만 쓰고, 기간이 지나면 지웁니다.

5. 알아 둘 것

  • 삭제하면 진행 기록, 가상 재화, 구매한 아이템을 되살릴 수 없습니다.
  • 사용하지 않은 유료 재화가 있으면 삭제 전에 환불 가능 여부를 문의해 주세요.
  • 광고 회사가 따로 가진 정보는 기기의 광고 ID 를 재설정하거나 삭제하여 연결을 끊을 수 있습니다.
